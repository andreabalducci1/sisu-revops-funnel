# Copy, funnel copywriting

Write copy that converts, step by step.

## Prerequisites
Read `memory/identity/business.md`, `memory/identity/offer.md`,
`memory/funnel/strategy.md`, `memory/knowledge/frameworks.md`.

## Workflow

1. Ask which step to work on (or "all").
2. For each, apply the frameworks in `frameworks.md` (AIDA / PAS / BAB plus page anatomy):
   - **Landing**: eyebrow, headline (benefit, not feature), italic second line, subhead,
     three value bullets, CTA, form label, honest proof line, preview card.
   - **Quiz**: question wording and the four option labels per dimension. Options must be
     honestly worded at every level, including the worst one.
   - **Report**: this body is generated by Claude per lead. Tune the prompt and tone rules
     in `lib/anthropic.ts`, not static copy.
   - **Book**: eyebrow, headline, description (restate the benefit of the call, reassure).
   - **Thanks**: eyebrow, headline, body, three next steps.
3. Offer two or three variants for the landing headline (the highest leverage element).
4. Get sign-off from Andrea.
5. Save to `memory/funnel/copy.md` AND apply in `config.ts`.

## Rules
- English. Voice: problem-first, plain, radically candid.
- **No em-dashes anywhere.** Use commas, colons, parentheses, or a single hyphen.
- One CTA per step.
- No invented testimonials, numbers, or logos.
- Avoid "supercharge", "unleash", "game-changer", "leverage", "synergy", "10x".
- Concrete and specific beats generic.
